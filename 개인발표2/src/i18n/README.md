# 언어와 통화 표시

- `messages.js`: 메뉴, 입력 안내, 알림 등 화면 문구의 한국어 → 영어 사전
- `places.js`, `attractions.js`: 국가·도시·항공사·관광지 이름
- `translate.js`: 화면 표시용 `t()` 함수. 공항 영문명은 기존 데이터에서 가져옵니다.
- `locale.js`: 언어 저장, 날짜·금액 표시, 예산 환산. `KRW_PER_USD = 1400`은 **시연용 고정 환율**이며 실제 환율이 아닙니다.

새 서비스 문구는 사전에 등록한 뒤 JSX에서 `t("한국어 문구")`로 표시합니다. 사용자 이름, 사용자 작성 질문, 카드 별명은 번역하지 않습니다. 검색 값과 예약 데이터는 기존 값을 유지합니다.

가격과 할인은 원화로 계산·저장하고 영어 화면에서만 USD로 환산합니다. 달러 예산 입력은 원화로 환산해 검색하며, 언어 변경 시 예산 입력을 초기화합니다. 원문 운임 출처의 금액은 출처에 명시된 통화를 유지합니다.

검증: `node --test src/i18n/locale.test.js src/data/paymentPromotions.test.js`
